Are you still worried about which skill to choose? Now you can get them all!
For players, the first 60 levels provide skill points every 3 levels, and the next 40 levels provide skill points every 2 levels, totaling 40 points,
For pets, Starting from level 2, each level provides  skill point, a total of 9 points, which can fill up the skill tree.
In addition, disabling this mod will not cause activated skills to become ineffective.(But if  you open the skill tree UI, corresponding points will be reset)
