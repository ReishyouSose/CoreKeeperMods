# Fantasy-book page-turn rendering

The animated page turn uses three IMGUI layers, drawn in this order:

1. `Page1.png` — the complete static book.
2. The destination page controls and artwork.
3. One transparent turning-sheet overlay from `Page2.png` through `Page8.png`.

`Page9.png` is the same resting book as `Page1.png`, so neither endpoint is
drawn as an overlay.

## Why the animation frames must be overlays

`GUI.DrawTexture` alpha-blends textures by default. This only reveals content
drawn earlier when the later texture contains transparent pixels. A full opaque
book frame will always hide the controls below it, regardless of draw order.

Each animation frame therefore retains only the moving sheet. Pixels belonging
to the unchanged book are transparent. The overlay is generated by comparing
each frame with `Page1.png`, finding the changed horizontal span on every
scanline, and retaining that complete span. Retaining the full span is
important: making only individually changed pixels opaque creates holes where
the turning sheet happens to use the same parchment color as the resting page.

## IMGUI event handling

During a turn, destination content is rendered only for `EventType.Repaint`.
This keeps it visible beneath the overlay without allowing hidden controls to
process mouse or keyboard events. Once the animation ends, controls resume
normal IMGUI event handling.

Keyboard and gamepad page navigation are also ignored until the animation
finishes. This prevents rapid tab input from restarting the turn midway.

Both page interiors are wrapped in matched `GUI.BeginGroup(pageRect)` /
`GUI.EndGroup()` pairs. Unity documents that controls inside a group are clipped
to its rectangle. This prevents labels, dropdowns, and dynamic content from
bleeding into the binding, page ornaments, or transparent animation regions.

The animation intentionally always uses the reverse frame sequence. With the
current overlay artwork this reveals the destination's left page first, which
matches the UI's reading and interaction order. Using the opposite direction
would reveal the persistent right page first and makes the content transition
look less natural.

## Regenerating overlays

When replacing the page-turn artwork:

1. Keep `Page1.png` and `Page9.png` as identical resting-book frames.
2. Export `Page2.png` through `Page8.png` as full-size aligned frames.
3. For each animation frame and each scanline:
   - compare its pixels with `Page1.png`;
   - find the first and last changed pixel;
   - preserve every source pixel between those positions;
   - make all pixels outside that span transparent.
4. Preserve the original 290×184 dimensions and point filtering.

- `GUI.DrawTexture`: https://docs.unity3d.com/ScriptReference/GUI.DrawTexture.html
- `GUI.BeginGroup`: https://docs.unity3d.com/ScriptReference/GUI.BeginGroup.html
- IMGUI basics and per-frame `OnGUI`: https://docs.unity3d.com/Manual/gui-Basics.html
