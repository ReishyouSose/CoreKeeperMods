# Contribution Guidelines

We welcome all feedback, bug reports, and code contributions!

## Issues
If you encounter a bug or have a suggestion, please open an Issue. Please provide as much detail as possible, including your Player.log if it's a crash or bug related to gameplay.

## Pull Requests
**We highly encourage Pull Requests!** Whether it's a bug fix, a performance improvement, or a new feature, your help is greatly appreciated.

- If your PR fixes a specific issue, please link it in the description.
- If you're adding a new feature, please explain the reasoning and how it works.
- By submitting a pull request, you confirm that you have read and agree to the Pugstorm Modding EULA.
- All PRs will be reviewed and merged if they align with the project's goals. 

## Community & Discussion
For general questions, feedback, or to discuss the codebase, feel free to join the [Core Keeper Discord Modding Channel](https://discord.com/channels/851842678340845600/1083718032574140436).

Thank you for helping make these mods better!
